Transparency

Every set, every epoch, on the record.

Singleton publishes each predicate set as a Merkle root and anchors it in the HumanRegistry contract. Verifiers only accept proofs against anchored sets, so the registry can't quietly add fake humans or drop real ones. This node runs the sandbox network with synthetic holders.

Verify it yourself

Download a set, rebuild the Merkle tree (sorted SHA-256 leaves of 0x00‖pubkey, nodes 0x01‖left‖right) and compare the root with the anchored calldata.

curl -s {{.BaseURL}}/api/sets/{{.T.epoch.ID}}/human | jq '.root, (.members | length)'
go run ./cmd/singleton verify-root -url {{.BaseURL}} -epoch {{.T.epoch.ID}} -set human
{{end}}
